Лендинг «Новый год в Чебере»

Структура:
- index.html — семантическая разметка
- styles.css — адаптивные стили desktop/tablet/mobile
- script.js — маска телефона, базовая валидация, success-state без перезагрузки
- assets/background.jpg — единый длинный фон всей страницы
- assets/cheba.png — предоставленный персонаж, фон удалён только вокруг него
- assets/cheber-venue.jpg / yaraton-venue.jpg — изображения площадок, взятые из предоставленного референса

PDF-ссылки пока оставлены временными, как в ТЗ:
/files/cheber-menu.pdf
/files/cheber-program.pdf
/files/yaraton-menu.pdf
/files/yaraton-program.pdf

Форма сейчас фронтенд-демо. Для реальной отправки заявки нужно подключить endpoint/CRM/почтовый сервис вместо демонстрационного success-state.


Фоны: каждый экран использует отдельный файл bg-screen-1.jpg … bg-screen-4.jpg. Они нарезаны последовательно из одной мастер-композиции, поэтому стыки между секциями совпадают без полос и резких переходов.
